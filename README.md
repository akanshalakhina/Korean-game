# 🇰🇷 Korean Quest — Fun Korean Learning Game

A gamified web app designed for complete beginners to learn the Korean language (Hangul) through interactive games, audio pronunciation, word-by-word sentence breakdowns, and structured repetition writing practice.

---

## ✨ Key Features

1. **✍️ 10x Repetition Screen Practice**:
   - Practice writing words repeatedly with instant character verification.
   - Built specifically for beginners to build muscle memory and character mastery.

2. **🔤 Hangul Alphabet Master**:
   - Consonants, vowels, and syllable block construction breakdown.
   - Phonetic romanization guides with sample words.

3. **🎮 Interactive Gamified Modes**:
   - **Flashcard Drill**: Tap to flip, listen to Korean pronunciations, and test recall.
   - **Speed Quiz**: Fast-paced multiple choice challenge with timer and instant score rewards.
   - **Word Match**: Pair English words with their Korean counterparts.
   - **Sentence Builder**: Construct Korean sentences piece-by-piece with translations.

4. **🏆 Gamification & Progress**:
   - XP points system, level tracking, daily streaks, and unlocked achievement badges.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/akanshalakhina/Korean-game.git
   cd Korean-game
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5174/` (or the port indicated in your terminal).
